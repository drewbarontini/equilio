# Equilio

**Create value.**

Equilio is a living operating system for modern product teams. It helps teams transform complexity into coherent value through craft, quality, and momentum.

As AI accelerates output, judgment, shared understanding, and coherence become increasingly important. Equilio helps teams move **coherently**, not merely faster.

**Intuition → Integration → Iteration**

### Philosophy

The three Models remain the foundation:

- [**Value Creation**](philosophy/value-creation.md) — Build the right things.
- [**Quality Refinement**](philosophy/quality-refinement.md) — Elevate what exists.
- [**Strategic Momentum**](philosophy/strategic-momentum.md) — Sustain forward movement.

[Product Equilibrium](philosophy/product-equilibrium.md) describes the adaptive balance between creation and refinement, sustained by momentum. **Balance is motion, not stasis.**

### Flow

**Sense → Form → Decide → Deliver → Learn**

Five movements describe how product work happens:

| Movement | Core concept | Principle |
| --- | --- | --- |
| **Sense** | Work Registry | Work emerges from reality. |
| **Form** | Work Formation | Give work the shape it needs. |
| **Decide** | Product Current | Judgment determines the next move. |
| **Deliver** | Integrated Delivery | Teams create value. |
| **Learn** | Product Memory | Reality responds; understanding changes direction. |

These are teaching movements, **not mandatory gates**. Straightforward Fixes and Improvements can move directly into delivery. Experiments can happen wherever uncertainty requires testing.

Read [Equilio Flow](flow/README.md) for Work Types, Work Forms, Experiments, and delivery practices.

### Focus

**Product Current** is the living, shareable synthesis of what we're working on, why it matters, and what we're learning:

- **Themes** — Five strategic priorities.
- **Work** — Three active **Streams**, each with **Live / Building / Next Bets**, plus independent **Enablers** and **Experiments** sections.
- **Memory** — Five connected views: **Feedback → Signals → Decisions → Releases → Updates**.

Product Current guides strategic attention; it is **not** the full Work Registry or a gate for every piece of work.

[Learn about Equilio Focus](focus/README.md) · [Use the Product Current template](focus/product-current-template.md)

## One Continuous System

Philosophy guides judgment throughout. Flow moves work and generates evidence. Focus compresses strategic understanding and directs attention. New learning changes the next move.

The objective is **coherent value creation**, not maximum output.
