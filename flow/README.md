# Equilio Flow

**How we work.**

Equilio Flow tells the story of how work emerges from reality, takes shape, creates value, and changes understanding.

**Sense → Form → Decide → Deliver → Learn**

| Movement | Concept | Principle |
| --- | --- | --- |
| **Sense** | Work Registry | Work emerges from reality. |
| **Form** | Work Formation | Give work the shape it needs. |
| **Decide** | Product Current | Judgment determines the next move. |
| **Deliver** | Integrated Delivery | Teams create value. |
| **Learn** | Product Memory | Reality responds; understanding changes direction. |

## How It Works

**Sense — Work Registry.** Capture and classify work from customers, the product, the business, and the team. The five work Types are **Idea, Task, Fix, Improvement, and Bet**.

**Form — Work Formation.** Recognize clusters and choose the lightest useful structure: an **Issue** (atomic work), **Batch** (related work), or **Project** (coordinated commitment). These are options, not a progression.

**Decide — Product Current.** Use the living strategic view to guide attention and priorities. It is a filter, **not a gate**: routine Fixes and Improvements needn't appear in Product Current to move forward.

**Deliver — Integrated Delivery.** Bring together people, context, and practices to ship functioning software. **Bamboo Teams**, **Build Dynamics** (Forging, Refining, Accelerating), and **Project Engine** support the work at the appropriate scale.

**Learn — Product Memory.** Observe feedback and outcomes. Integrate **Feedback → Signals → Decisions → Releases → Updates** into the living Memory views of Product Current.

An **Experiment** is a **Task designated for learning** (for example, with an Experiment type or label). It tests uncertainty wherever needed and may inform a Stream or independent exploration; it is not a fourth Work Form or required step.

The five movements describe a **continuous, adaptive loop**, not mandatory sequential stages. Learning can redirect work in progress, and new signals can enter at any time.
